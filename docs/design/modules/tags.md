## 已确认规则

### CATEGORY-01：首版七个通道

- 首版通道为：吐槽、避雷、安利、互助、搭子、科技、情感。
- 原名称“找搭子”已简化为“搭子”，“科技前沿”已简化为“科技”；后续口语提及“找搭子”不重新更名。
- 失物招领等细分内容通过适合的通道和自定义标签表达，不新增同名通道。

### CATEGORY-02：一帖一个通道

- 每帖必须归属一个通道，不同时投放多个通道；从通道内发帖默认归入当前通道。
- 已发布帖的大通道不能更换，按[内容管理 EDIT-POST-01](moderation.md)执行。
- 例如找篮球搭子归入“搭子”，可自定义添加 `#篮球`；安利食堂可添加 `#食堂`。各通道的具体标签由作者和实际内容形成。

### TAG-DIRECTION-02：通道必选，自定义标签选填，不设统一分类

- 首版保留用户自定义 `#标签`；作者可以完全不加标签，不影响所属通道和正常发布。
- 不增加“通道 → 中间分类 → 细标签”的平台分类层级，不维护全站或逐通道的固定主题词表。
- 不做审核员纠正主题、移除无关标签、锁定标签的专项治理，也不做标签新增审批、合并和停用管理。
- 不做标签专项治理不取消普通违规内容举报、处罚或违规昵称头像处置。
- `#tag` 表示用户自定义主题词，不因此引入话题广场、热搜、关注或推荐算法。具体输入方式随 UI 设计确定。

### TAG-01 / TAG-02：标签范围与数量

- 每帖最多三个自定义标签，允许不选；标签不逐一成为导航树节点，也不是切换大通道的入口。
- 同一个词可在不同通道使用，不要求统一标签清单；点击标签默认查看全站同标签帖子，切到具体分类后只返回该分类内容。
- 普通文字搜索按[SEARCH-01](navigation.md)匹配标题、正文和标签，沿用搜索页的分类分组和排序；独立标签结果使用下方精确匹配与混排规则。
- 仍有编辑权限的作者可修改帖子标签，保留原帖及已有互动，不重新发布、不更换通道，见[EDIT-POST-01](moderation.md)。

### TAG-03：自定义与已有标签复用

- 作者可输入自定义标签，也可搜索和复用已有标签；常用词或相近词提示仅作为输入辅助，不构成平台固定词表。
- 不做人工同义归并，不根据相近词自动增加标签、分类或屏蔽范围。
- 不根据正文关键词强制归类。例如“骑车去健身”不等于整篇帖子的主题是骑行；首版不增加模型分类功能。

### TAG-SELECT-01：添加标签

- 发布确认页与作者编辑页提供独立标签区域，点击打开底部面板；正文中的 `#文字` 不自动转成标签。
- 输入时提示当前账号可访问、未屏蔽分类的已发表帖子所使用的标签，也可创建新词。未发布、已删除或下架内容的标签不作为提示来源。提示失败仍可手动添加。
- 已选标签可逐项移除，最多三个；每个 1–10 字，允许汉字、ASCII 英文字母、数字和下划线，不含空格、换行、表情或内嵌 `#`。自动去掉首尾空格和开头的一个 `#`；英文不分大小写，展示保留原大小写，重复词只计一次。
- 点击「完成」将当前有效输入与已选内容返回原页面，不提交帖子；直接关闭面板丢弃本次面板修改。输入校验失败保留已输入和已选内容。
- 标签随草稿、发布尝试、失败重试及编辑提交保存；结果未知时沿用原命令和原标签核对。

### TAG-FILTER-01：独立标签结果

- 信息流卡片和详情展示作者所选标签；点击 `#篮球` 打开独立结果页，默认全部分类。
- 只匹配实际添加了该标签的帖子，英文大小写不区分。`#篮球比赛` 不属于 `#篮球`，标题或正文出现同词也不构成标签归属。
- 全部分类按首次发布时间、同时间发布序号降序混排，不按分类分组。首版一次查看一个标签，无热度排序或多标签组合筛选。
- 顶部可切具体分类，切换后选中态与查询范围一致并重取第一页，迟到响应不能覆盖新范围。
- 刷新沿用当前标签和分类；分页绑定标签、分类、账号、页大小和分类屏蔽版本，固定首屏发布上界。游标失效提示刷新。
- 打开详情再返回保留列表和阅读位置；离开标签页回到原信息流或详情时保留来源页状态。
- 每次查询保留登录、最终 C Safety Gate、当前内容可见性和账号分类屏蔽检查；不新增标签屏蔽。

### TAG-FILTER-02：首页入口关系

- 首页既有「筛选」继续修改账号级分类屏蔽，不改为标签筛选，不增加第二套多标签状态。
- 标签页按单标签精确匹配和最新发布混排；普通搜索允许关键词匹配标题、正文和标签，继续使用原分类分组及相关度／最新排序。

### TAG-BLOCK-DEFERRED-01：主题屏蔽留到后续版本

- 用户确认“可以，屏蔽后续版本可以设计”：首版不提供中间分类、标签或主题偏好的屏蔽功能，不增加对应设置入口。
- 通道列表、搜索、热榜、帖子、收藏、分享及私信来源帖均不执行旧中间分类屏蔽；不显示“所属分类已被屏蔽”拦截状态。
- 互动提醒不因旧分类屏蔽而隐藏标题或摘要。系统推送默认隐藏内容、账号访问、删除和下架等独立规则继续有效。
- 私信拉黑及其黑名单、普通举报和处罚保留，不受主题屏蔽延期影响。
- 后续版本重新设计屏蔽对象及作用范围，不预先继承旧中间分类、细标签或关键词方案。

## 实现与验收

- 本次实现与验收由 CUSTOM-TAGS-01 记录，覆盖发布、编辑、草稿、重试、公开投影、已有词提示、普通搜索及独立标签结果；不提升其他模块的历史验收结论。
- 新客户端通过 `X-Post-Tags: v1` 获取标签，旧响应保留封闭 DTO。旧客户端编辑时省略标签字段会保留当前标签，新客户端显式空数组清空标签。
- C33 为前向迁移；旧客户端兼容不表示旧服务可在 C33 上回退运行。旧服务的严格列权限检查会拒绝新增标签授权，部署故障应前向修复或执行经过验证的数据恢复，不能降低权限检查或运行 down 迁移。发布演练分别验证兼容回退和此边界下的安全拒绝、数据保留与新服务重新启用。
- 举报保存举报时同一公开版本的标签证据，之后编辑不改写旧证据；不新增标签专项治理。
- 主题屏蔽已明确不在首版，后续版本单独设计。
